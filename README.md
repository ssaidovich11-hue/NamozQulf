# НамозҚулф (Android)

Барномаи Android барои сабти дастии вақтҳои намоз, ёдрас 20 дақиқа пеш ва режи��и оромии ихтиёрӣ.

## Сохтан ва насб кардан

Лоиҳаро дар Android Studio кушоед ва Gradle Sync кунед. Сипас аз менюи **Build > Build Bundle(s) / APK(s) > Build APK(s)** APK созед. Барои насб, телефонро ба компютер пайваст карда, APK-ро ба телефон гузаронед ва кушоед.

## Истифода

1. Барои ҳар намоз вақтро пахш карда интихоб кунед.
2. Давомнокии режими оромиро интихоб кунед.
3. **Нигоҳ доштан ва фаъол кардан**-ро пахш кунед.
4. Барои фаъол шудани режими оромӣ, иҷозати огоҳиномаҳо ва **«Халал нарасонед»**-ро дар Android диҳед.

Ёдрас 20 дақиқа пеш оғоз мешавад. Режими оромӣ дар ҳамон лаҳза фаъол шуда, баъд аз вақти интихобшуда пас аз вақти намоз анҷом меёбад (масалан, агар 30 дақиқа интихоб кунед, дар маҷмӯъ тақрибан 50 дақиқа фаъол мемонад). Android дар телефонҳои оддӣ иҷозати пурра қулф кардани экран ё барномаҳои дигарро намедиҳад. Зангҳои фавқулода ва истисноҳои иҷозатдодаи Android метавонанд дастрас бошанд.

> Эзоҳ: вақти ҳушдор метавонад дар баъзе телефонҳо аз сабаби сарфаи батарея каме дер шавад. Баъди иваз кардани вақтҳо тугмаи нигоҳ доштанро ҳатман пахш кунед.
